⚙️ 2. 5단계 캐스케이드 파이프라인
1
Rule Engine / Policy 즉시 <10ms · $0
사전 정의 규칙, 금지어, 보안 정책 기반으로 즉시 처리.
  • 키워드 라우팅 테이블 자동 매핑 (카이로스 / 랄프 / 온톨로지 등)
  • Prompt Injection 방어 · 절대 규칙 강제 적용
↓ bypass 조건 미충족 시 다음 단계로
2
KMS + Vector Search 로컬 · ~50ms · $0
Obsidian Vault(7,681 노트) + ChromaDB 벡터 DB 하이브리드 검색.
  • ontology_hybrid_query.py → runtime.route 자동 실행
  • 벡터 유사도 + 구조적 그래프 탐색 동시 수행
↓ 신뢰도 임계값 미달 시 다음 단계로
3
Local LLM — LM Studio 로컬 GPU · ~500ms · $0
localhost:1234 로컬 모델 직접 추론. Health Score 기반 자동 Bypass.
  • 운영 모델: qwen3-coder-next / exaone-4.0-32b / gpt-oss-120b
  • Health Score ≥ 85 → 정상 처리 / <70 → 자동 Bypass
↓ Health Bypass 또는 품질 미달 시 다음 단계로
4
Mid API — MiniMax / Haiku Cloud · ~1s · Economy
중간 비용 Cloud API로 구조화 응답 생성.
  • MiniMax M2.7 (기본 대화) / Claude Haiku (경량 처리)
  • 경량 대화 · 요약 · 분류 · 자동화 태스크 최적화
↓ 복잡 추론 / 아키텍처 판단 필요 시 최종 단계로
5
High API — Claude Sonnet / Opus Premium · ~3s · 최후 수단
최고 품질 Cloud LLM — 복잡한 추론·설계·전략에만 사용.
  • Sonnet 4.6 → 코드 생성 / 수정 / 리뷰 (Medium 비용)
  • Opus 4.6 → 계획 · 분석 · 전략 · 오케스트레이션 (Premium 비용)
